# ColdDrop

## Register

product

## Users
Rim moves large videos and other files between an Android phone and a Windows PC to review and download them.

## Product Purpose
One shared gallery, direct transfers over the same local network, original files without recompression. The Windows app hosts the library. No hosted storage subscription.

## Design Direction
Apply the installed Claude Code Impeccable product guidance. The user explicitly requested immediate implementation without planning, interviews, tests, verification, or subagents; those instructions override skill interviews and review steps. This document records implementation choices, not additional confirmed user preferences.

## Design Principles
The gallery comes first. Pair devices once. Show transfer progress and connection state honestly. Make previews and saving obvious. Keep controls usable on a phone and with a mouse and keyboard.

## Accessibility
Semantic controls, visible focus, labelled icon buttons, reduced motion, large touch targets, and keyboard-dismissable previews.
